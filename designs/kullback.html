Three agents, one loop.

Kullback runs as three agents taking turns until the environment holds and a model clears the bar.

The loop.

Code decides pass or fail from what the model changed, not from what it said. A judge model can take a pass away but never give one.

What a week of traces turns into.

Data

The records your runs touched, with the values they saw.

Tools

One function per tool, behaving the way the real one did in the logs.

Rules

Your policy, turned into checks that run before every write.

User

A simulated user who knows only what the real one knew.

Verifier

One per task. It looks at the final data and says pass or fail.

Every value points back to the line in your trace it came from.

Built so you can trust the numbers.

Grade what changed, not what was said.

Code checks the final data: required writes present, forbidden writes absent, no rule broken, the user's questions answered. Where a judgment call cannot be avoided, two judge models each cite the span they read, and a person settles any disagreement.

A stand-in is reported, never counted.

Tool calls go to code first, then to an exact recording, and only then to a model stand-in. A run that touched a stand-in anywhere is left out of every number.

Any model behind one id.

Built-in adapters and the models.dev registry mean a provider nobody wrote code for is one flag away. Keys come from the environment, never from the command line.

You read everything it makes.

Every eval case and training example Kullback writes is a file you can read. Reject one and it rewrites it. The runner is frozen only after a person confirms it, and every verdict carries the hash of the environment and the runner it ran on.

Three ways to run it.

As a pipeline.

Six commands, from ingesting traces to the report, in CI or on a laptop.

As a screen.

A terminal screen that watches stages, gates and spend as the build runs.

As a loop.

Resume from the cache and keep improving, or hand the session to the model.

Tests run fully offline and builds reproduce byte for byte from fixtures.
